# Astvard

Портал [astvard.online](https://astvard.online) и мод для нашего сервера Valheim.

Под одной крышей две почти не связанные вещи:

| Что | Где | На чём |
|---|---|---|
| **Портал** — сайт, личный кабинет, админка, вход через Steam, вайтлист, статус серверов | `server.js`, `src/`, `client/`, `public/`, `db/` | Node.js без фреймворков, Postgres |
| **Мод** — панель управления прямо в игре: постройки по шаблонам, рельеф, руны | `valheim-mod/` | C# net472, BepInEx + Jötunn |

Общего кода у них нет: собираются, запускаются и ломаются порознь.

---

## Игрокам: как поставить мод

Мод **не обязателен** — на сервер пускают и без него. Он нужен ради панели в игре.

Понадобится **Valheim из Steam**. Версия из Game Pass и консоли не подойдут: на сервере выключен crossplay, они этот сервер просто не увидят.

### 1. BepInEx — загрузчик модов

Ставится один раз, дальше не трогается. Качать здесь:
[BepInExPack Valheim](https://thunderstore.io/c/valheim/p/denikson/BepInExPack_Valheim/) — кнопка **Manual Download**.

Папку с игрой проще всего найти через Steam: правой кнопкой по Valheim → **Управление** → **Просмотреть локальные файлы**. Обычно это `…\steamapps\common\Valheim`, и в ней лежит `valheim.exe`.

В скачанном архиве открой папку `BepInExPack_Valheim` и положи **её содержимое** в папку с игрой. Рядом с `valheim.exe` должны появиться `winhttp.dll`, `doorstop_config.ini` и папка `BepInEx`.

### 2. Мод

Скачай [последний релиз](https://github.com/official-fedorenko/astvard/releases/latest) и распакуй в ту же папку с игрой — файлы добавятся внутрь `BepInEx`.

Должно получиться так:

```
Valheim\
    valheim.exe
    winhttp.dll
    BepInEx\
        plugins\
            AstvardServerMod.dll
            Jotunn.dll
```

Windows помечает скачанное из интернета, и из-за этого файлы иногда не подхватываются. Если что-то пойдёт не так: правой кнопкой по скачанному архиву → **Свойства** → внизу галочка **«Разблокировать»** → ОК, и распаковать заново.

### 3. Проверить

Запусти игру как обычно, через Steam. Зайди в мир и открой инвентарь клавишей **Tab** — над ним появится деревянная панель с кнопками.

Если панели нет, открой `BepInEx\LogOutput.log` в папке игры и поищи строки:

```
Loading [Jotunn ...]
Loading [AstvardServerMod ...]
```

Нет их — значит BepInEx не встал или файлы легли не в ту папку.

### Как попасть на сервер

Сервер скрытый, в общем списке серверов его нет. Адрес и доступ — на [astvard.online](https://astvard.online): вход через Steam, потом «Запросить доступ».

Пока заявку не одобрили, игра при заходе скажет, что ты **забанен**. Это не так — просто тебя ещё нет в списке.

### Обновления

Обновляться необязательно: за несовпадение версий никого не отключают. Если на сервере версия новее, мод один раз за заход напишет об этом в чат — и всё.

## Что умеет мод

- **Постройки** — шаблоны сервера и свои, копирование, проекция с прилипанием и выравниванием земли.
- **Рельеф** — дорожки и площадки, мосты, заборы кольцом, выравнивание.
- **Функции** — сбор продукта из печей и плавилен в сундуки и наполнение их сырьём, ремонт построек вокруг.
- **Руны** — внутриигровая валюта за время в мире.

Что из этого открыто обычному игроку, решает админ сервера: часть может быть закрыта или стоить ресурсов из сумки.

## Разработчику

### Портал

```bash
docker compose up -d   # Postgres рядом
npm install
npm start              # сайт на :3001
```

Схему база получает сама при старте из `db/schema.sql`. Ключи — в `.env`, его в репозитории нет.

### Мод

Собирается только там, где установлен Valheim: проект ссылается на его библиотеки напрямую.

```bash
dotnet build valheim-mod/AstvardServerMod/AstvardServerMod.csproj -c Release
dotnet test valheim-mod/AstvardServerMod.Tests
```

Тесты покрывают `Geometry.cs` — единственный файл мода, который ничего не знает ни про Unity, ни про игру, и потому проверяется где угодно.

Архивы для раздачи собираются скриптами: `tools/release/` — для релизов GitHub, `tools/thunderstore/` — пакет для менеджеров модов. У каждого свой README с подробностями.

### Развёртывание

`deploy/README.md` — как всё ставится на VPS: сайт, nginx, игровой сервер в Docker.

### Заметки

`CLAUDE.md` в корне и `valheim-mod/CLAUDE.md` — то, чего не видно в коде: почему сделано именно так и на чём здесь уже обжигались. Стоит прочитать до первой правки.

## Чем это было раньше

Портал вырос из самодельной админ-панели для учёта компании (тот же Node.js без фреймворков) — отсюда его структура и часть кода. Модули про сотрудников, инструмент и автопарк игровому порталу не нужны и вычищаются.
